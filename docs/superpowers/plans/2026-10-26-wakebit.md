# Wakebit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tray app (Windows now, macOS later) that blocks sleep and simulates activity in Full or Light mode, with a fast Working/Resting toggle.

**Architecture:** A platform-independent `engine` drives a `Platform` interface (sleep lock, cursor, idle time, editor window, typing). `platform/windows` implements it with syscalls (no cgo); `platform/darwin` with cgo (written now, verified later on a Mac). `tray` is a thin UI over engine + config.

**Tech Stack:** Go 1.22+, `fyne.io/systray`, `golang.org/x/sys/windows`, `golang.org/x/sys/windows/registry`.

**Spec:** `docs/superpowers/specs/2026-10-26-wakebit-design.md`

## Global Constraints

- No admin rights to run or install; install target `%LOCALAPPDATA%\Wakebit` (macOS: `~/Applications`); autostart via HKCU Run key (macOS: user LaunchAgent).
- Working = mode active: sleep (system + display) blocked AND simulation running. Resting = nothing blocked, nothing simulated.
- Mode is independent of status; both persist across restarts.
- Light: every interval cursor nudges for 1–2 s and returns to the original position. Full: every interval type the current time into a temp-dir file open in Notepad, char by char with short random delays. Default interval 60 s.
- Simulation is skipped for a cycle if user input was seen within the last interval-independent threshold of 5 s.
- Tray: green icon = Working, grey = Resting; tooltip shows state; left click toggles status; menu: Mode (Full/Light), Pause/Resume, Autostart, Quit.
- Single binary, `go build -ldflags "-H=windowsgui"` for Windows; Windows build must succeed via `GOOS=windows` from WSL/Linux; unit tests must pass on Linux.

## Review Focus

- Toggle Working→Resting while a Full cycle is mid-typing: typing aborts promptly, sleep lock released (Task 2).
- Config file missing or corrupt: app starts with defaults (Mode=Light, Working=false, IntervalSec=60) (Task 1).
- Cursor restored to the exact original position even if a cycle is cancelled mid-nudge (Task 2).
- Notepad window not found / user closed it: cycle logs and retries next tick, never crashes or types into another window (Task 2, 3).
- Second launch while already running: second instance exits (single-instance mutex) (Task 4).

### Task 2: Engine

**Files:**
- Create: `internal/engine/engine.go`, `internal/engine/platform.go`, `internal/engine/engine_test.go`

**Interfaces:**
- Consumes: `config.Mode`.
- Produces:
  ```go
  // platform.go
  type Platform interface {
      PreventSleep(on bool) error
      CursorPos() (x, y int, err error)
      MoveCursor(x, y int) error
      IdleFor() time.Duration                        // time since last real user input
      OpenEditor(path string) (Editor, error)        // opens file in Notepad/TextEdit
  }
  type Editor interface {
      Focus() error                                  // finds window by title, brings to front; error if gone
      Type(ctx context.Context, text string, delay func() time.Duration) error // aborts on ctx cancel
      Close()                                        // releases handles only, does not close the editor
  }
  // engine.go
  type Engine struct{ /* unexported */ }
  func New(p Platform, tempDir string) *Engine
  func (e *Engine) Apply(mode config.Mode, working bool, interval time.Duration) // idempotent; (re)starts or stops the loop
  func (e *Engine) Stop()                                                         // = Apply(..., false, ...), blocks until loop exits
  ```
  Behaviour: when working, `PreventSleep(true)` immediately, then a cycle per interval (first cycle immediately); on stop `PreventSleep(false)`. Cycle is skipped when `IdleFor() < 5s`.

- [ ] **Step 1: Write failing tests** with a fake Platform (records calls; clock via short intervals of ~10 ms): `TestWorkingBlocksSleepAndRestingReleases`, `TestLightCycleMovesCursorAndRestoresOriginal`, `TestLightCancelMidNudgeRestoresCursor`, `TestFullCycleWritesTimeFileAndTypesHHMMSS` (typed text matches `^\d{2}:\d{2}:\d{2}$`, file exists in tempDir), `TestFullAbortsTypingOnStop`, `TestCycleSkippedWhenUserActive` (IdleFor=1s → no moves/typing, sleep still blocked), `TestEditorFocusErrorDoesNotCrashAndRetriesNextTick`, `TestApplyIsIdempotent` (two identical Apply calls → one PreventSleep(true)), `TestModeSwitchWhileWorkingChangesBehaviour`.
- [ ] **Step 2:** `go test ./internal/engine/` → FAIL.
- [ ] **Step 3:** Implement. One goroutine per Apply with a cancellable context; nudge = move cursor a few px along a small path over ~1.5 s, with `defer MoveCursor(orig)`; Full reuses one editor/file per run of the loop and reopens it if `Focus` fails.
- [ ] **Step 4:** `go test -race ./internal/engine/` → PASS.
- [ ] **Step 5:** Commit `feat: engine with light and full cycles`.
